# Repository Rules

## Privacy in source files

- This is a public repository. Do not add personal names or other personally identifying information to generated source-file headers or comments.
- In particular, do not add Xcode-style `Created by <personal name>` comments. Omit the author line entirely; a generic copyright-free file header is acceptable when needed.
- Before committing or pushing, search newly added and modified files for personal names and generated author headers.
